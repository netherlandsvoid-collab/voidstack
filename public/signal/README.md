# Studio Signal sample artwork

The four WebP images here were generated for Nexirel's approved Studio Signal redesign using the built-in image generation tool, then inspected and optimized to WebP.

- kinetic-type.webp: cobalt/chrome kinetic typography study.
- iridescent-forms.webp: iridescent glass loop study.
- kinetic-people.webp: red editorial typography/portrait study.
- coastal-study.webp: coastal architectural study.

They are display artwork for explicitly labeled sample records. They do not represent downloadable project files or real creators' submissions. Existing user media is not modified.
