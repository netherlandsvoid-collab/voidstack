ART WORLD — MULTI-PAGE WEBSITE STARTER

PAGES
- index.html — Home
- explore.html — Explore Art
- artists.html — Artists
- sell.html — Sell Your Art
- about.html — About Us
- contact.html — Contact
- styles.css — shared styling for all pages
- script.js — shared interactions

HOW TO RUN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Double-click index.html to open the site in your browser.
4. Use the navigation to visit each independent HTML page.

IMPORTANT
This is a front-end prototype. Artist/contact/newsletter forms do not send or save data. Artwork, artists, biographies and prices are sample content. Images and Google Fonts load from the internet. For a production launch, replace demo content with approved listings and connect a secure backend, image storage, authentication, and a payment provider.


SHOPPING BAG + CHECKOUT DEMO
- cart.html — view, change quantities, or remove items from your bag.
- checkout.html — enter delivery details and review the demo order.
- confirmation.html — demo order confirmation.
- Artwork can be added from the home page featured works and Explore Art.
- The bag is stored in this browser using localStorage and shared across these pages.
- Checkout does NOT process payments or submit/save orders. The ₦5,000 delivery amount is only a sample estimate. For real orders, connect a secure backend and a payment provider (for example Paystack or Flutterwave), validate prices server-side, and add order notifications.
