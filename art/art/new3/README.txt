ART WORLD — CATEGORY MARKETPLACE WEBSITE

PAGES
- index.html — Home
- paintings.html — Paintings collection
- sculptures.html — Sculptures collection
- photography.html — Photography collection
- digital-art.html — Digital Art collection
- african-art.html — African Art collection
- contact.html — Contact
- cart.html — Shopping bag
- checkout.html — Demo checkout
- confirmation.html — Demo order confirmation
- styles.css — shared styling
- script.js — shared interactions and cart logic

HOW TO RUN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in your browser.
4. Use the top navigation to open each independent category page.

IMPORTANT
This is a front-end prototype. Product listings and prices are sample content. Images and Google Fonts load from the internet. The shopping bag uses browser localStorage. Checkout does not process payment or send/save real orders. For a production launch, connect a secure backend, approved artwork listings, and a payment provider such as Paystack or Flutterwave.
